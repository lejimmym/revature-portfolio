Docker Desktop + PostgreSQL setup in VSC
Start Docker Desktop

in a terminal type:
docker run -d --name chinook-postgres -p 5432:5432 -e POSTGRES_USER=chinook -e POSTGRES_PASSWORD=password -e POSTGRES_DB=chinook postgres:17

Make sure the container is running then in VSC open PostgreSQL
Add a new connection
Server Name: localhost
User Name: chinook
Password: password
Advance -> Port: 5432
Connect
